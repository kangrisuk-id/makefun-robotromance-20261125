# Robot Romance — Candidate Tournament

Bounty: **Robot Romance: One-Line Pickup Lines for AI** (`u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa`)
Judge brief criteria, in order (stand-up comic judge, pairwise):
1. **C1 — Pickup-ness:** the line is a pickup line aimed at a robot or an AI (a joke about anything else loses to any pickup line aimed at a robot/AI).
2. **C2 — Joke lands:** setup and punch arrive inside the one line; the laugh comes from the machine premise, not a generic compliment.
3. **C3 — Freshness:** sidesteps the worn robot moves (batteries, charging, rebooting) or twists one in a way nobody expects.
4. **C4 — Voice:** sounds like something a person would really say to a machine; voice and rhythm read cleanly in one breath.
5. **C5 — Economy:** every word earns its place; no throat-clearing before the punch.

Scoring: 1–5 per criterion, total /25. First differing criterion decides a head-to-head unless a later one differs by much more.

## Devices used (15)

- **A** direct address with a machine premise
- **B** versus-frame (you vs. other models / humans)
- **C** promise + dare
- **D** rule-of-three rhythm
- **E** concrete number
- **F** before / after (fine-tune arc)
- **G** pain → offer
- **H** live verb doing the work
- **I** meta / self-aware (the line knows it is a line)
- **J** flattery via a machine trait
- **K** rhyme / familiar frame twisted
- **L** twist on a worn move (charging)
- **N** role reversal / data bargain
- **O** API / protocol metaphor
- **P** open-source / code metaphor

- **#19 (22):** rule-of-three machine traits + a clean punch question; loses to #25 only on economy (C5 4 — "how are you still single?" is a beat longer than it needs to be).

- **#15 (15):** the "I" is ambiguous (human selling themself to a robot?) — C1 3, fails the pickup-ness gate first.
